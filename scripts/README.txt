================================================================================
 [1] INSTALL  ................................................... 3 steps
================================================================================

  STEP 1 . Open the game folder
           Steam > right-click METAL GEAR SOLID > Manage > Browse local files

  STEP 2 . Copy everything in this zip into that folder
           (next to "METAL GEAR SOLID.exe"). Say YES to replace.

  STEP 3 . Double-click  INSTALL.bat
           Wait for "installed", press a key. Play!

  That's it. Start the game from Steam as normal.


================================================================================
 [2] KEYS  ...................................................... in game
================================================================================

     F8  .....  New lighting  <->  original lighting      (starts ON)
     F7  .....  HD textures   <->  original textures      (starts ON)
     F6  .....  Image effects: sharpen, bloom, grade      (starts OFF)

  Flip F7 / F8 any time to see the difference.


================================================================================
 [3] WHAT IT DOES
================================================================================

  * HD textures for the whole game, made from the original art.
  * HD weapon and item icons in the menus and the HUD.
  * Real, motivated lighting. The HUD, text and radar stay exactly
    as the game draws them.
  * No ReShade needed. Saves are not touched.

  The lighting is EXPERIMENTAL: if a spot looks wrong, press F8.


================================================================================
 [4] UNINSTALL
================================================================================

  1. Double-click  UNINSTALL.bat   (puts the game data back)
  2. Delete the files you copied in step 2.

  Or just use Steam > Properties > Installed Files > "Verify integrity
  of game files". That restores everything.


================================================================================
 [5] PROBLEMS?
================================================================================

  "not the stock files this pack was built for"
       Your game data is already modified (another mod, or an update).
       Verify integrity of game files in Steam, then run step 3 again.

  "Close the game first."
       Exactly that. Then run it again.

  Want image effects on at start?
       MGSM2Fix.ini > [ImageFx] > StartOn = true

  Steam Deck / Linux: not tested yet.
